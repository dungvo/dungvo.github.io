# Playlab spec-driven tooling profile

- Compatible GitHub Spec Kit baseline observed in the existing Selflo setup: `1.1.3`.
- Profile here: documentation-first, engine-neutral game design.
- Canonical shared artifacts are root `docs/` and `specs/`; experience artifacts live under `experiences/<slug>/`.
- Codex entry point: `AGENTS.md`; Claude entry point: `CLAUDE.md`.

This scaffold intentionally stores templates and policy, not generated source or deployment configuration. Before upgrading or running an initializer, review its diff; no initializer may overwrite project instructions, decisions or design documents.
