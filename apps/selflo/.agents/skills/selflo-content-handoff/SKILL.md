# Selflo Content Handoff

Read `apps/selflo/AGENTS.md`, the current work package and `content-workspace/REPO_WORK_IN_PROGRESS.vi.md`. Update only the relevant record; do not replace canonical research, contract, source, or review artifacts with a summary.

Record completed work, changed files, channel/status, commands/validators actually run, owner decisions, source/rights/knowledge/contract blockers, local uncommitted state that must be preserved, and exactly one next step. Link stable repository paths/IDs across repos; do not commit personal absolute paths or symlinks.

Use `Parked` with reason/resume conditions when appropriate. Do not claim Released/closed without owner acceptance and executable evidence.
