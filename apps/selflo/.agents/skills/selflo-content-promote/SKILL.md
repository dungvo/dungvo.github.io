# Selflo Content Promotion

Read `apps/selflo/AGENTS.md`, content lifecycle/commands, work package, review evidence, and relevant shared contract. Resolve the exact item IDs, current channel, target channel, canonical source, ledger, validators, app capability, and rollback before mutation.

Promotion requires explicit authorization for the requested stage. Never infer owner approval, rights status, knowledge check, `--push`, or Release permission. Do not pass confirmation flags merely to satisfy a script. If a required gate is missing, stop with a concise blocker and recommended evidence.

Run only the scoped command, inspect the diff/generated output, run documented validators, and report actual results. Update WIP/handoff without rewriting unrelated content. Commit/push only when separately authorized.
